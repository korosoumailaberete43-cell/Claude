# Kit de production : Écho de U Kabala n°3

## Le principe
1. **Vous** remplissez les dossiers : une fiche + des photos par rubrique.
2. **Claude Code**, ouvert dans ce dossier, lit les fiches et les règles (`CLAUDE.md`), puis produit le bulletin
   en couleurs, étape par étape. Vous validez chaque étape avant la suivante.

## Ce que vous devez faire
1. **Déposer les anciens numéros** (PDF ou images de chaque page) dans `01_REFERENCES/anciens_numeros/`.
2. **Remplir chaque `fiche.md`** des dossiers `02_` à `14_` (s'ouvre avec le Bloc-notes, VS Code ou Typora).
   - Une rubrique sans activité ce trimestre : écrivez simplement « Aucune activité » en haut de la fiche.
   - Si vous préférez, transmettez un document Word ou des notes vocales transcrites dans le dossier : Claude les lira.
3. **Déposer les photos** dans le sous-dossier `photos/` de chaque rubrique :
   - nom : `AAAA-MM-JJ_nom-activite_01.jpg` (ex. `2026-07-12_anniversaire-ou_01.jpg`) ;
   - 2 à 5 photos par activité, les plus nettes, avec des visages ; pas de captures WhatsApp floues si l'original existe.
4. **Ouvrir Claude Code dans ce dossier** et suivre `PROMPTS.md` dans l'ordre.

## Contenu du dossier
| Élément | Rôle |
|---|---|
| `CLAUDE.md` | Les règles que Claude Code applique (contenu, charte, étapes). Ne pas supprimer. |
| `PROMPTS.md` | Les messages à envoyer à Claude Code, étape par étape. |
| `01_REFERENCES/` | Charte JCI, logos officiels, anciens numéros. |
| `02_` à `14_` | Les rubriques du bulletin, dans l'ordre de parution. |
| `20_PRODUCTION/` | Ce que Claude produit (plans, maquettes, PDF). |

## Liste de contrôle avant de lancer Claude
- [ ] Anciens numéros déposés
- [ ] Toutes les fiches remplies (ou marquées « Aucune activité »)
- [ ] Photos déposées et nommées
- [ ] Mot du Président fourni (ou ses idées clés)
- [ ] Tableau d'honneur de juillet, août, septembre fourni
