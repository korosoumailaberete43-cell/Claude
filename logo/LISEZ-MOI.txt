FORMATS
-------
Chaque version existe en SVG, PDF, EPS, PNG et JPEG.
   SVG / PDF / EPS : vectoriels, pour l'impression et les imprimeurs.
   PNG             : fond transparent, pour le web et les documents.
   JPEG            : fond plein (blanc, ou Nuit pour les versions blanches).
Les textes du logo sont vectorisés : aucune police n'est nécessaire pour les ouvrir.
